Configuración de IA Gratuita (OpenRouter)

¿No tienes API key?
1. Ve a openrouter.ai/keys
2. Crea una cuenta gratuita
3. Crea una nueva API key
4. Copia la API key (comienza con sk-or-v1-)
5. Pégala aquí y prueba la conexión


OpenRouter es 100% Gratuito: Usa modelos como MiMo-V2-Flash de Xiaomi con límites generosos. No requiere tarjeta de crédito. Si la IA falla, automáticamente usa el algoritmo básico inteligente.
